# Nouveautés 0.8.38

Cette version applique les règles de navigation corrigées par l’utilisateur après la 0.8.37.

- L’arborescence gauche affiche des dossiers et les racines des supports ; les fichiers restent dans le panneau droit.
- La racine SD est ouverte au premier accès, ou USB si la SD est absente. La navigation reste mémorisée pendant la session de l’OS.
- À droite : clic pour sélectionner, double-clic pour ouvrir. À gauche : clic pour afficher le contenu du dossier à droite.
- Les chevrons signalent l’existence de sous-dossiers, détectés progressivement ; un dossier composé seulement de fichiers n’en affiche pas.
- SD et USB appartiennent à l’arborescence ; USB apparaît uniquement si le support est monté. Le libellé de support n’emploie plus « Racine carte SD ».
- La recherche et le tri disposent d’icônes. Le menu Navigation disparaît. Édition regroupe notamment Renommer et Supprimer.
- Git est regroupé dans un sous-menu contextuel adapté au dossier sélectionné, et son icône n’est plus affichée systématiquement.
- Les nouveaux noms par défaut et les noms des scripts fournis sont anglais. Les traductions de l’interface et les données personnelles sont conservées.

Voir [EXPLORATEUR.md](EXPLORATEUR.md) pour les gestes et menus, [LISEZ_MOI.md](LISEZ_MOI.md) pour la mise à jour firmware/SD et [VERIFICATION.md](VERIFICATION.md) pour les résultats réellement exécutés. Les mesures de performances 0.8.37 restent historiques ; aucun nouvel essai matériel n’est annoncé.

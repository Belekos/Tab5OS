Tab5 Pocket: a freely redistributable demonstration created for Tab5OS, with no commercial ROM or BIOS.
Arrow keys: scroll. A (Z or W): invert the palette. B (X): recenter. Escape: exit.
Demonstration code: CC0; generator: tools/native-apps/gameboy/make_demo.py.
DejaVu glyphs: license included in System/fonts. Rebuild with Python 3 + Pillow.
To play, open the .gb file in Files, then choose Run. Copy other .gb ROMs here
or elsewhere on the SD card. The engine supports monochrome Game Boy only.

Volume: Page Up/Down or the touch slider. M: mute. Ctrl+S: save. Ctrl+R: restart. F1: keyboard help.

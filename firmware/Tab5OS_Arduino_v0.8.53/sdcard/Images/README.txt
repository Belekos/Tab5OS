DRAWING - Tab5OS

Open Drawing from Home or Explorer / Open with.
Supported formats: BMP, baseline/grayscale JPEG, PNG, WebP and T5I projects.
Imports retain their original dimensions, without automatic downscaling.
If the format or available memory prevents import, the current document is preserved.
Progressive JPEG and automatic EXIF orientation are not supported.
Animated WebP: first frame only.

Left click: color 1. Right click: color 2, without a context menu.
In the palette, left click assigns color 1 and right click assigns color 2.
Touch and keyboard selection use the color currently being edited.
Relief fill shades the chosen paint color: color 1 for a primary click,
color 2 for a secondary click. Zero height or lighting intensity gives a flat fill.
Text: click the image and type; Enter commits, Escape cancels.
The options panel starts closed and overlays the image without moving it.
The wheel zooms; Hand or the middle button pans without painting.
Coordinates appear on hover; measurements follow the current gesture.
Initial tool size: 2 px. X swaps the colors; the Colors panel also offers this action.
Local warp uses a brush. Image / Transform affects the active layer's selection,
or the whole image when nothing is selected.
Ctrl+Z / Ctrl+Y: undo / redo. Ctrl+S: save.
T5I preserves layers and transparency; BMP/JPEG flatten on white.
Save explicitly. An operation may be refused when its required memory is unavailable.

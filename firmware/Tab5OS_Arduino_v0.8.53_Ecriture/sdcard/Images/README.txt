DESSIN — Tab5OS 0.8.35

Ouvrir Dessin depuis l’accueil ou Ouvrir avec dans l’explorateur.
Formats : BMP, JPEG standard/gris, PNG, WebP et projets T5I.
Les imports conservent les dimensions originales, sans réduction automatique.
Si le format ou la mémoire ne le permettent pas, le document courant est conservé.
JPEG progressif et orientation EXIF automatique non gérés ; WebP animé : première image.

Clic gauche : première couleur. Clic droit : seconde couleur, sans menu.
Texte : cliquer dans l’image puis écrire. Entrée valide ; Échap annule.
Le volet d’options est fermé au départ et s’ouvre au-dessus de l’image.
La molette zoome. Main ou bouton central déplace la vue sans peindre.
Les coordonnées s’affichent au survol ; les mesures suivent le geste en cours.
La taille initiale est 2 px. X échange les couleurs, également via Couleurs.
Déformation locale : pinceau ; Image / Transformation : image entière.
Ctrl+Z / Ctrl+Y : annuler / rétablir. Ctrl+S : enregistrer.
T5I conserve calques et transparence ; BMP/JPEG aplatissent sur blanc.
Enregistrer explicitement. Une opération peut être refusée si la mémoire manque.

DRAWING — Tab5OS 0.8.35

Open Drawing from Home or Explorer / Open with.
BMP, baseline/grayscale JPEG, PNG, WebP and T5I keep their original dimensions.
No automatic downscaling. A failed import preserves the current document.
Progressive JPEG and automatic EXIF orientation are not supported.
Animated WebP: first frame only.

Left button: first colour. Right button: second colour, no context menu.
Text: click the image and type; Enter commits, Escape cancels.
Options start closed and overlay the image without moving it.
Wheel zooms; Hand or middle button pans without painting.
Coordinates appear on hover. Initial tool size: 2 px. X swaps colours.
Local warp uses a brush; Image / Transform operates on the whole image.
Ctrl+Z / Ctrl+Y undo / redo. Ctrl+S saves.
T5I preserves layers and transparency; BMP/JPEG flatten on white. Save explicitly.
An operation may be refused when its required memory is unavailable.

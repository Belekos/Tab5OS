Game Boy Color

Open a .gbc file in Files. Use Open with to choose gameboy_color.app.elf for a .gb file.
Arrows: direction; Z or W: A; X: B; Enter: Start; Backspace: Select; Esc: save and exit.
Touch controls, Save and Restart are available. Saves and last snapshot: /Saves/GBC.
Tab5_Color.gbc is an original freely redistributable Tab5OS homebrew demonstration, licensed CC0-1.0.
It is not a commercial game. Its generator is in tools/native-apps/gameboy-color.
ROM limit: 4 MiB. No Game Boy Advance. Hardware performance has not been measured.

Ouvrir une ROM .gbc dans Fichiers. Reprise du dernier état compatible et sauvegardes dans /Saves/GBC.
La démonstration est librement redistribuable (CC0-1.0). Aucun jeu commercial n’est fourni.

Volume: Page Up/Down or touch slider. M: mute/unmute. Ctrl+S: save snapshot. Ctrl+R: restart. F1: keyboard help.

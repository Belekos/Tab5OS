Tab5 Pocket : démonstration libre créée pour Tab5OS, sans ROM commerciale ni BIOS.
Flèches : défiler. A (Z ou W) : inverser la palette. B (X) : recentrer. Échap : quitter.
Code de démonstration : CC0, génération dans tools/native-apps/gameboy/make_demo.py.
Glyphes DejaVu : licence livrée avec System/fonts. Reproduction : Python 3 + Pillow.
Pour jouer : ouvrir le .gb depuis Fichiers puis Exécuter. Copier vos autres ROMs .gb ici
ou ailleurs sur la SD. Le moteur couvre la Game Boy monochrome uniquement.

Volume : Page haut/bas ou curseur tactile. M : muet. Ctrl+S : sauvegarder. Ctrl+R : recommencer. F1 : aide clavier.

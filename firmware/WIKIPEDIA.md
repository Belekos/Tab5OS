# Wikipedia: pages and archives

## Reading

A page now combines paragraphs, a short table and an illustration when space permits. Tables no longer stop after their first cell. Cell links remain accessible, wide tables scroll horizontally, and very tall cells can be read by scrolling vertically.

Articles are still loaded in 32 KiB windows. A page contains at most twelve layout elements and one decoded illustration at a time; remaining elements are accessible on the next page. Tables are grouped into batches of rows, with at most 128 cells resident in memory. The table index is bounded to 2,048 entries; beyond that, the article text remains readable. These limits protect memory without removing text.

Text height is measured on the actual LVGL widget after Arabic/Persian shaping. Link colors and the illustrations button follow the OS palette.

## Reading and search

Results fill each page continuously: saved copies, ZIM archives, then online results. A single local copy no longer pushes all subsequent results onto another page. Remaining results and the cursors for both sources are retained when returning to the previous page; duplicate titles are filtered across the last 32 pages.

The **…** button on an offline result can delete its saved copy. For a ZIM result, it explicitly offers deletion of the entire archive, with confirmation of its name or path. Other documents in the directory are preserved. **Remove from list** in the library continues to keep the file.

The image icon in the reading toolbar shows or hides illustrations without leaving the article. **Ctrl I** does the same. **Backspace**, **Escape** and **Alt Left** move back through reading history, then return directly to results. Arrow keys, Page Up/Down and Space provide navigation; inside a scrolling table, the arrows move the table first. Page buttons with no destination disappear.

HTML tables are now displayed as aligned cells: headers, borders, horizontal and vertical merged cells, with links preserved. Wide tables scroll horizontally. The reader loads large tables in sections; previous/next buttons move between these sections. Nested tables remain text inside their containing cell, and grids wider than 64 columns use the text fallback. This reader does not interpret Wikipedia's complete CSS layout.

New ZIM extractions benefit from these cells offline. For older **saved article copies** whose tables were already flattened into text, opening while connected rebuilds the structure; the old copy remains readable without a network connection. Install the firmware and MicroPython 0.8.19 modules together.

## Loading reliability

ZIM reads are split into blocks of at most 32 KiB and honor cancellation. XZ decoding yields regularly, in 8 KiB output steps, while retaining the compatibility path for older archives declaring a 64 MiB dictionary. Memory requests are checked before large allocations; insufficient memory must produce an error, not a falsely successful load.

The link index is read in 512-byte blocks and resumes from its last cursor between pages. It is limited to 4 MiB, with at most 4,096 bytes per line. Pagination measures the area around the screen rather than unnecessarily reprocessing the entire article.

A damaged JSON cache no longer blocks reading by itself. Cache cleanup remains limited to filenames generated by the reader. Illustration loading honors cancellation, rejects oversized indexes and stops if memory is insufficient.

These changes retain the existing article-size and decoder limits. They do not guarantee compatibility with every Kiwix archive. Responsiveness on Tab5 and operation with your actual archives still need verification.

## Using archives

Search remains shared across saved copies, ZIM files and the network. An annotation indicates the source; local articles are searched first.

**Add an archive already on the SD card**: Options > Add a ZIM archive from the SD card > choose `.zim` or `.zimaa`, then its language. For segmented Tab5 downloads, choose their `manifest.json`. The title index is read and must provide an article before registration. Adding an archive is fast because it retains its path; it does not copy or decompress the entire encyclopedia.

**Find a ZIM**: open Available archives on the Wikipedia home screen. Added archives in all languages are displayed with their language and name. Read opens the index directly. External ZIM files offer Change language and Remove from list; removing an entry never deletes the file. A path that can no longer be found remains visible. Complete downloaded archives for the current language also appear here; their manifests retain the edition's language.

Available articles shows local results for the selected language. A ZIM read error must no longer become a simple "No articles found": it is reported while other sources remain accessible. ZIM files added under the wrong language in an older version can be corrected from Available archives. The registry retains up to 32 external ZIM files instead of four.

The underlying formats are unchanged: ZIM 5/6, single files and segments supported by the existing reader, and bounded XZ/Zstandard decompression. Not every ZIM in the Kiwix catalog has been validated. An archive whose index uses an unsupported format reports its error. Four small real archives from the libzim reference datasets were used to verify registration, persistence and search; this does not constitute testing every large Wikipedia archive.

The reader retains memory limits and does not replace a full HTML/CSS browser. It supports tables on Wikipedia pages.

## Startup fix

The footer extended ten pixels beyond the graphics surface. Creating it triggered `OSError: 22` before the menu appeared. Its coordinates are corrected and dimensions are now validated on the Python side. Install the new `tab5ui.py` and `tab5wikiui.py` modules; no archives or saved pages need to be deleted.

## Decoder memory

Large-window Zstandard blocks are decoded incrementally in C++ until the end of the requested article. A contiguous buffer retains the required history and is freed immediately afterwards. The compatibility-buffer limit remains 8 MiB. A remaining error reports the requested allocation, free PSRAM and largest free block. Testing your edition on the physical device remains necessary.

Update the firmware as well as the SD resources: the decoder is in the firmware. No archive deletion is required.

## Downloading and refreshing

The catalog lets you choose the language, then an edition with or without illustrations. The ↻ icon on an existing edition restarts its download after confirmation; it is also available in Available archives for recognized Wikipedia editions. A new copy of an imported ZIM is downloaded separately and preserves the original file.

Chunks are downloaded from a remembered HTTPS mirror. Another mirror is tried if the server refuses resumption. Exact size and SHA-256 are read from Kiwix metadata. After downloading, the entire archive is read back and verified before being marked complete; this read can take time and its progress is visible. Pausing during verification preserves the chunks: resuming restarts only their verification. Network, size, mirror-identifier and content errors are distinguished.

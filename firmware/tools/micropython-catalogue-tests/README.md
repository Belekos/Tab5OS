# Catalogue MicroPython

Depuis la racine du projet :

    python -B tools/micropython-catalogue-tests/test_catalogue.py Tab5OS_Arduino_v0.8.15_Ecriture/sdcard/MicroPython/lib

Le test simule les primitives du stockage avec des fichiers temporaires et utilise le vrai gestionnaire de transactions. Aucun matériel requis ; il ne valide pas le transport USB physique.

Tab5OS 0.8.53 - M5Stack Tab5 / ESP32-P4

The English installation guide is docs/INSTALL_EN.md at the repository root:
https://github.com/Belekos/Tab5OS/blob/main/docs/INSTALL_EN.md

This repository contains source code and partial SD resources. Precompiled firmware, a complete SD package and a Tab5OS M5Burner listing are not yet published. The sketch's sdcard folder alone is not a complete installation package.

For an existing Tab5OS installation, use the application OTA image with the built-in updater and update the matching SD resources. Back up personal files and follow the resource repair/update procedure without replacing the entire /System directory.

A merged first-install image replaces the internal P4 Flash, including settings and internal data. Never write the application-only OTA image at address 0x0.
